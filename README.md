# rjtvr.github.io

Personal portfolio of Rajat Verma, live at <https://rjtvr.github.io/>.

Two static pages (`index.html` and `workshop.html`) styled with [Oat](https://oat.ink) and `assets/site.css` (served minified as `assets/site.min.css`; regenerate with `python scripts/minify-css.py` after editing). Served by GitHub Pages from `master`: open `index.html` in a browser to preview.

Commits follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/); see [CLAUDE.md](CLAUDE.md#commit-conventions).
